# LIVED. - Life in Numbers

A premium, minimal life calculator.

## Features
- Alive mode with live years/months/days/hours/minutes/seconds
- Remember Someone mode with birth and death dates
- Estimated heartbeats with a live counter in alive mode
- Life-in-weeks visualization
- 70/75/80/85 year lifespan assumption selector
- Full-moon estimate
- Share result using Web Share API or clipboard
- Generate a 1080x1350 share card
- Responsive mobile/desktop UI
- Basic SEO landing routes
- Dates remain client-side, no account/database required

## Run
npm install
npm run dev

## Important
After extracting the project, run `npm install` before `npm run dev`. Tailwind CSS is included in the dependencies and configured for Tailwind v4.
